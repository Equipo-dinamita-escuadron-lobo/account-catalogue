# Ping Pong
Para utilizar Swagger, primero se debe hacer ping u otra petición antes de acceder a la interfaz de Swagger.

```
http://localhost:8080/api/accountCatalogue/test/ping
```
**URL Swagger**
```
http://localhost:8080/swagger-ui/index.html#/
```
